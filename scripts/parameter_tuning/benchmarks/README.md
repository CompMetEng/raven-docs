# Parameter benchmarks: fseof, remove_genes, connect_blocked_reactions

Scripts for the benchmarks page of the parameter-tuning documentation: `fseof` at three values of `flux_eps` and a sweep of `n_steps`, `max_fraction` and `correlation_threshold` on iJO1366 (target `EX_succ_e`), `remove_genes` after deletion of `b1779` from e_coli_core, and `connect_blocked_reactions` `threshold` on a synthetic network.

## Inputs and environment

The models are the `iJO1366.xml.gz` and `textbook.xml.gz` (e_coli_core) files bundled with cobra 0.32.1. The SHA-256 of both is written into the output JSON files. Python runs need cobra, optlang and gurobipy; the MATLAB script needs RAVEN and Gurobi.

| Variable | Meaning |
| --- | --- |
| `STUDY` | this folder |
| `RAVEN_TOOLBOX` | raven-toolbox checkout (`94f3940`); its `src` goes on `PYTHONPATH` |
| `BENCH_PY` | Python interpreter with cobra 0.32.1 and gurobipy |
| `R` | RAVEN checkout (`2d0630e`) |
| `GUROBI_HOME` | Gurobi installation that supplies the licence |
| `COBRA_DATA` | `cobra/data` folder of the Python environment |

The module names in the wrappers are site-specific; other systems need an equivalent environment.

## Commands

```bash
sbatch --export=ALL -A <account> -o small.log     $STUDY/sbatch_small.sh
sbatch --export=ALL -A <account> -o sweep.log     $STUDY/sbatch_sweep.sh
sbatch --export=ALL -A <account> -o mat_small.log $STUDY/sbatch_mat_small.sh
```

The wrappers run the following commands, with three repeats per configuration. `mat_small.m` reads the unzipped e_coli_core file from `$MODEL`.

```bash
python small.py --out results/small.json --repeats 3
python fseof_sweep.py --outdir results --repeats 3
python gapfill_threshold.py --out results/gapfill_threshold.json
```

## Outputs

| File | Content |
| --- | --- |
| `small.py` to `results/small.json` | `remove_genes` with `blocked_reactions` set to `constrain` (default), `remove` and `keep` and the unmodified model; `fseof` at `flux_eps` 1e-8, 1e-7 and 1e-6 with software versions and input checksums. |
| `fseof_sweep.py` to `results/sweep.json`, `results/sweep_summary.tsv`, `results/sweep_targets.tsv` | One row per configuration and repeat: target counts, targets added and dropped relative to the default run, and noise targets (flux standard deviation below 1e-6). `sweep_summary.tsv` is kept in this folder; the other two are regenerated by the run. |
| `gapfill_threshold.py` to `results/gapfill_threshold.json` | `connect_blocked_reactions` at `threshold` 0.01, 0.1, 0.5 and 1.0: draft with an import (at most 0.5), reaction A to B, dead-end B, template exchange `EX_B`. |
| `mat_small.m` | MATLAB `removeGenes` on e_coli_core with and without `removeBlockedRxns`, printed to the log. |
| `versions.py`, `env_py.sh` | Software versions written into the JSON files; environment set-up of the wrappers. |
